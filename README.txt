국방예산 프로그램별 재원 대시보드

실행: index.html을 Chrome 또는 Edge 브라우저로 여세요.
별도 설치, 인터넷 연결, 서버 없이 실행됩니다.

기능
- 부문 및 회계구분 연동 필터
- 4개 주요 지표와 8개 시각화
- 프로그램 검색, 표 정렬, 필터 결과 CSV 다운로드
- 원본 엑셀 다운로드
- 모바일 화면 대응

금액 단위: 억 원. 데이터는 재원_원본.xlsx의 작성 시점 스냅샷입니다.
엑셀 파일을 수정해도 대시보드 데이터가 자동 갱신되지는 않습니다.
data.js에 32개 프로그램/차감 항목 데이터가 저장되어 있습니다.
증감률은 표시된 금액으로 직접 계산하므로 PDF의 반올림 전 계산값과 다를 수 있습니다.
프로그램 상세 합계는 원문의 소계와 2026년·2027년 각각 1억 원 차이가 있습니다.
원본 값을 수정하지 않고 그대로 사용했습니다.

파일 구성
index.html: 대시보드 화면
style.css: 반응형 디자인
app.js: 필터, 그래프, 검색, 다운로드 기능
data.js: 엑셀 추출 데이터
재원_원본.xlsx: 대시보드 작성에 사용한 엑셀 사본
